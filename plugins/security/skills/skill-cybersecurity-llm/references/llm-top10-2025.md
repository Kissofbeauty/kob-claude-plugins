# OWASP Top 10 for LLM Applications:2025 — Quick Reference

> เน้น defensive: อธิบายความเสี่ยง + control · ไม่ใส่ payload โจมตีพร้อมใช้

## LLM01:2025 — Prompt Injection
input ผู้ใช้/ข้อมูลภายนอก (เว็บ, เอกสาร, RAG) แทรกคำสั่งที่เปลี่ยนพฤติกรรมโมเดล (รวม indirect injection ผ่าน content ที่โมเดลอ่าน)
- ตรวจ: user input ต่อตรงเข้า prompt โดยไม่แยกชั้น, ไม่มี guardrail/instruction hierarchy
- ✅ แยก system/user, จำกัดสิทธิ์, ตรวจ output, ใช้ allowlist สำหรับ action

## LLM02:2025 — Sensitive Information Disclosure
โมเดลเผย PII/secret/ข้อมูลภายใน (จาก training/context/RAG) ออกไปใน response
- ตรวจ: ใส่ secret/PII เข้า prompt/context ตรง ๆ, ไม่มี output filtering/redaction

## LLM03:2025 — Supply Chain
โมเดล/dataset/adapter/plugin จากแหล่งไม่น่าเชื่อถือ, model จาก hub ที่ไม่ verify, dependency ของ AI stack มี CVE
- เชื่อมกับ `skill-cybersecurity-supply-chain`

## LLM04:2025 — Data and Model Poisoning
training/fine-tune/RAG data ถูกวางยา → bias/backdoor
- ตรวจ: แหล่ง data ที่รับเข้า RAG/training มี validation/provenance ไหม

## LLM05:2025 — Improper Output Handling
เอา output ของโมเดลไปใช้ต่อแบบไม่ sanitize → **RCE/SQLi/XSS/SSRF**
- ❌ `exec(llm_output)`, `db.query(llm_output)`, render HTML จาก output ตรง ๆ
- ✅ treat output เหมือน untrusted user input เสมอ (validate/escape/parameterize)

## LLM06:2025 — Excessive Agency
agent/tool มีสิทธิ์/ฟังก์ชันเกินจำเป็น → โมเดลถูกหลอกให้ทำ action อันตราย
- ตรวจ: tool ที่ลบ/จ่ายเงิน/ส่งเมล/เรียก API ภายใน ให้สิทธิ์กว้างไป, ไม่มี human-in-the-loop/approval
- ✅ least privilege ต่อ tool, ยืนยันก่อน action ที่กลับไม่ได้

## LLM07:2025 — System Prompt Leakage
system prompt มีข้อมูลลับ (key, business rule, internal) แล้วรั่ว
- ✅ อย่าใส่ secret ใน system prompt, ถือว่า system prompt อาจรั่วเสมอ

## LLM08:2025 — Vector and Embedding Weaknesses (RAG)
- embedding/RAG: data leak ข้าม tenant, ไม่ filter ตาม permission ตอน retrieve, injection ผ่านเอกสารใน vector store
- ✅ access control ที่ retrieval layer, แยก namespace ต่อ tenant

## LLM09:2025 — Misinformation
โมเดล hallucinate ข้อมูลผิด แล้วถูกนำไปใช้ตัดสินใจ/แสดงต่อ
- ✅ grounding/citation, human review สำหรับ high-stakes, ไม่พึ่ง output ดิบในงานวิกฤต

## LLM10:2025 — Unbounded Consumption
ไม่มี limit ต่อ request/token/cost → DoS หรือค่าใช้จ่ายพุ่ง (รวม model extraction)
- ✅ rate limit, token/budget cap, timeout, quota ต่อ user
