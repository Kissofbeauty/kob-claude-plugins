# OWASP API Security Top 10:2023 — Quick Reference

> ตัวอย่างเป็น pseudo/JS/Python — pattern ใช้ได้ทุกภาษา/เฟรมเวิร์ก

## API1:2023 — Broken Object Level Authorization (BOLA)
endpoint รับ object id จาก user แล้วไม่เช็กว่า user เป็นเจ้าของ
- ตรวจ: `GET /orders/:id` → query ด้วย id ตรง ๆ โดยไม่กรอง `owner_id == current_user`
- ❌ `db.orders.find(req.params.id)` → ✅ `db.orders.find({_id: id, ownerId: req.user.id})`

## API2:2023 — Broken Authentication
- weak/ไม่มี auth บน endpoint, JWT ไม่ verify signature/`alg:none`, token ไม่หมดอายุ, ไม่มี rate limit บน login/OTP, credential ใน URL

## API3:2023 — Broken Object Property Level Authorization
รวม Mass Assignment + Excessive Data Exposure
- Mass assignment: bind body ตรงเข้า model (`User(**req.body)`) → user ตั้ง `is_admin=true` ได้
- Excessive exposure: ส่ง object ทั้งก้อน (มี password hash/internal field) ให้ client กรองเอง

## API4:2023 — Unrestricted Resource Consumption
- ไม่มี rate limiting / pagination / size limit → DoS หรือค่าใช้จ่ายพุ่ง (cloud/3rd-party/LLM cost)
- ตรวจ: query ที่ดึงทั้งตาราง, upload ไม่จำกัดขนาด, ไม่มี timeout

## API5:2023 — Broken Function Level Authorization
- endpoint ระดับ admin/privileged เข้าได้โดยไม่เช็ก role (`/admin/*`, `DELETE /users/:id`)
- ตรวจ: มี `@requires_role('admin')` / middleware ครบทุก privileged route ไหม

## API6:2023 — Unrestricted Access to Sensitive Business Flows
- business flow (ซื้อ/จอง/สมัคร/comment) ไม่มี anti-automation → scalping, fake accounts, spam
- ตรวจ: มี CAPTCHA/rate limit/device fingerprint บน flow ที่ละเอียดอ่อนไหม

## API7:2023 — Server Side Request Forgery (SSRF)
- ดึง URL จาก user input แล้ว fetch โดยไม่ validate (webhook, image-from-url, import)
- ✅ allowlist domain + บล็อก internal IP/metadata endpoint (169.254.169.254)

## API8:2023 — Security Misconfiguration
- CORS `*` บน authenticated API, missing security headers, verbose error/stack trace, HTTP methods เกิน, debug เปิด

## API9:2023 — Improper Inventory Management
- API version เก่า/`/v1` ที่ยัง expose, shadow/undocumented endpoints, host ทดสอบหลุด prod
- ตรวจ: เทียบ route จริง vs OpenAPI spec, หา `/internal`, `/debug`, `/test`

## API10:2023 — Unsafe Consumption of APIs
- เชื่อ data จาก 3rd-party API โดยไม่ validate, follow redirect ไม่จำกัด, ไม่ตั้ง timeout/size limit ตอน consume API ภายนอก
